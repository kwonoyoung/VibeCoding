인사발령 자료 분석

인사발령 엑셀·PDF를 학교·기관, 지역, 직렬·직군·과목 기준으로 빠르게 집계합니다.

⌂홈
사용 안내
1. 인사발령 파일 불러오기인사발령 엑셀(.xlsx/.xls) 또는 텍스트형 PDF 파일을 선택합니다.
2. 분석 기준 선택학교·기관, 지역, 직렬·직군·과목 중 필요한 기준으로 자동 집계합니다.
3. 결과 확인·다운로드전입·전출 명단을 검색하고 집계 결과를 엑셀로 다시 저장할 수 있습니다.
1. 파일 불러오기
불러온 파일이 없습니다.
2. 분석 기준 설정
파일의 머리글을 자동 분석해 선택한 기준과 가장 가까운 정보를 사용합니다.
전입·전출 열이 없는 파일은 발령구분·발령내용 텍스트를 이용해 판별합니다.
비워두면 전체 인사발령 자료를 집계합니다.
엑셀은 시트를 자동 선택하고 PDF는 전체 페이지를 분석합니다.
