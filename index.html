전북교육 업무지원 도구

급여·복무·재정 업무를 더 쉽고 정확하게 처리할 수 있도록 제작한 실무형 웹 도구입니다. 필요한 업무 카드를 선택하면 해당 계산기로 바로 이동합니다.

업무 도구 안내아래 이미지를 누르면 공무원 육아휴직수당 계산기 페이지로 이동합니다.

추천 업무 도구

사용 가능

공무원 육아휴직수당 계산기

육아휴직 시작일, 종료일, 월봉급액과 특수조건을 입력하여 월별 예상 지급액을 계산합니다.

이용 방법

01
이미지 또는 버튼 선택왼쪽의 대표 이미지를 클릭하거나 아래 바로가기 버튼을 누릅니다.
02
휴직 정보 입력시작일·종료일·월봉급액과 해당 특수조건을 선택합니다.
03
결과 확인 및 저장월별 계산 결과를 확인하고 필요하면 Excel 또는 PDF로 저장합니다.
